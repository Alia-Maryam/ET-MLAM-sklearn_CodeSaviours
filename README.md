📌 About This Notebook

This notebook is a hands-on, practice-oriented course for learning Scikit-learn (sklearn) and building machine-learning workflows in Python.

It is structured as a guided learning notebook: concepts are introduced with code examples, followed by practice-oriented sections so you can work through the material rather than only read the theory.

▶️ How to Run

1. Clone or download the project

Place the notebook in your working directory.

2. Create a Python environment

python -m venv .venv

Activate it:

Windows

.venv\Scripts\activate

macOS/Linux

source .venv/bin/activate

3. Install dependencies

pip install scikit-learn numpy pandas matplotlib seaborn jupyter

4. Start Jupyter Notebook

jupyter notebook

Then open the Scikit-learn notebook and run the cells from top to bottom.

📊 Model Evaluation

When working through the notebook, pay attention not only to whether a model produces predictions, but also to how its performance is measured.

Depending on the task, useful evaluation concepts include:

Accuracy

Precision

Recall

F1-score

Confusion matrix

Mean absolute / squared error

R² score

The appropriate metric depends on the machine-learning problem and the goal of the model.
